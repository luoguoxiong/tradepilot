## 1. 页面区块与字段清单

### 1.1 头部信息（FR-01）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| customerId | string | ✓ | 客户 ID |
| companyName | string | ✓ | 公司名 |
| score | number | ✓ | 评分百分比（🔥 Score 92%） |
| country / website | string | ✓/— | 国家 / 官网链接 |
| industryTags | string[] | — | 行业标签（如 Running / Sports） |
| inCrm | boolean | ✓ | 未入库时展示 [加入 CRM] |
| actions | — | ✓ | 加入 CRM / 🤖 AI 分析 / 📧 联系客户 / 更多 |

### 1.2 Overview 页签（FR-03/04）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| companySize | string | — | 公司规模（如 500+） |
| foundedYear | number | — | 成立时间 |
| customerType | string | — | 客户类型（Brand / Distributor / Factory…） |
| mainProducts | string[] | — | 主营产品 |
| productMatches | object[] | — | `[{ productId, productName, matchPct }]`（进度条） |

### 1.3 AI 客户洞察（FR-05，Insight Schema）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| purchaseProbability | number | ✓ | 采购概率百分比 |
| reasons | object[] | ✓ | 逐条判断原因（含 evidence/source），**必须展示** |
| nextAction | object | — | `{ type: "contact_decision_maker" | "generate_outreach" | "send_quote", label: "联系采购负责人 →", targetId }`，点击执行 |

### 1.4 Contacts 页签（FR-06）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| contactId / name | string | ✓ | 联系人 |
| title | string | ✓ | 职位（如 Purchasing Manager） |
| decisionInfluencePct | number | — | 决策影响力进度条 |
| email | string | — | 公开商务邮箱（合规来源） |
| actions | — | ✓ | 查看详情 / AI 生成开发信 |

### 1.5 其他页签（FR-07）

| 页签 | 列表字段 |
|---|---|
| Products | productId, productName, matchPct（复用 1.2） |
| Conversations | conversationId, channel(email), subject, lastMessageAt, unreadCount（复用 06） |
| Quotes | quoteNo, totalAmount, currency, status, createdAt（复用 09） |
| Orders | orderNo, amount, deliveryDate, status, risk（复用 10） |
| Activities | activityId, type(stage_change/email/quote/follow_up/note), summary, operatorType(ai/user), createdAt |

## 3. 接口详细定义

### 3.1 GET /api/v1/customers/{id}

响应 `data`：

```json
{
  "customerId": "cus_1", "companyName": "ABC Sports", "score": 92,
  "country": "US", "website": "https://…", "industryTags": ["Running", "Sports"],
  "stage": "negotiation", "inCrm": true,
  "overview": { "companySize": "500+", "foundedYear": 2008, "customerType": "Brand",
                "mainProducts": ["Running Shoes", "Sports"],
                "productMatches": [
                  { "productId": "prod_1", "productName": "Carbon Fiber Insoles", "matchPct": 92 },
                  { "productId": "prod_2", "productName": "Running Insoles", "matchPct": 85 } ] }
}
```

### 3.2 GET /api/v1/customers/{id}/insights

响应 `data`（Insight Schema 完整示例）：

```json
{
  "purchaseProbability": { "value": 92, "confidence": 0.88, "generatedAt": "2026-09-04T14:35:00Z",
    "reasons": [
      { "text": "产品高度匹配", "evidence": "官网在售跑鞋配件线", "source": "web_crawl" },
      { "text": "公司规模符合目标", "evidence": "员工 500+", "source": "web_crawl" },
      { "text": "存在 OEM 产品线", "evidence": "官网 OEM 页面", "source": "web_crawl" } ] },
  "nextAction": { "type": "contact_decision_maker", "label": "联系采购负责人 →", "targetId": "con_11" }
}
```

### 3.3 POST /api/v1/customers/{id}/analyze

请求：`{ scope: "overview" | "full" }` → 响应 `{ taskId }`；完成后 `insights` 更新。

### 3.4 POST /api/v1/contacts/{id}/generate-outreach

请求：`{ scenario: "cold_outreach" | "quote_followup", language?: "en" }`

响应：`{ draftId, conversationId, content }` —— 产出**草稿**进入 [06-AI销售工作台](./06-AI销售工作台.md) 流程，不直接发送。

## 4. 联动与边界

- 「AI 分析」只读推理：不修改客户字段；洞察结果带 `generatedAt` 供刷新判断。
- 「AI 生成开发信」「联系客户」均为建议动作，用户点击触发，外发受审批约束。
- 各页签数据均为对应模块列表接口的客户维度过滤（见上表复用关系）。
- 客户删除/合并等高危操作不在本页提供，走 [05-CRM客户中心](./05-CRM客户中心.md) + 审批。
