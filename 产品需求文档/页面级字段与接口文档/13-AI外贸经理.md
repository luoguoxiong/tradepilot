## 3. 接口详细定义

### 3.1 GET /api/v1/manager/overview

请求参数：`date`（默认今天）。
响应 `data`：`{ newCustomers: 28, newInquiries: 8, newQuotes: 12, dealsClosed: 2 }`。
口径：与 [15-数据中心](./15-数据中心.md) 统计接口同源。

### 3.2 GET /api/v1/manager/discoveries

响应 `data.items[]`：

```json
{ "discoveryId": "disc_1", "type": "opportunity", "title": "美国市场机会",
  "detail": "Carbon Fiber Insoles 相关询盘增加 28%",
  "evidence": [ { "text": "近 30 天询盘 18 → 23", "source": "analytics", "ref": "/analytics/drilldown?metric=inquiries&country=US" } ],
  "suggestion": { "label": "增加美国市场获客任务", "action": "start_lead_task",
                  "payload": { "parsed": { "targetMarket": "USA", "targetProduct": "Carbon Fiber Insoles" } } } }
```

### 3.3 POST /api/v1/manager/discoveries/{id}/execute

响应按 `suggestion.action` 分流：

- `start_lead_task` → `{ taskId }`（创建获客任务，见 [03-AI获客](./03-AI获客.md)）
- `enable_reactivation_strategy` → `{ strategyId }`（创建重新激活策略，见 [07-AI自动跟进](./07-AI自动跟进.md)；实际外发仍走各模块审批）

### 3.4 POST /api/v1/manager/reports/generate

请求：`{ period: "weekly" }` → 响应 `{ taskId, reportId }`（异步；完成前 `status=generating`）。

## 4. 联动与边界

- **洞察必须基于可核实数据**：`evidence` 必填且可下钻（ref 指向数据中心明细）；预测内容 `estimated: true` 标注。
- 「AI 自动处理」一键执行的是**建议动作的发起**，外发动作仍受审批约束。
- 一键动作白名单（需求 §7 已澄清）：`suggestion.action` 封闭为 `start_lead_task` / `enable_reactivation_strategy` 两个发起类动作；**一键仅创建可撤销的任务 / 策略，不产生对外或不可逆效果**，执行类动作不提供一键入口，新增 action 须遵守此原则。
- 指标底座来自 [15-数据中心](./15-数据中心.md)；效率数据来自 [02-AI数字员工中心](./02-AI数字员工中心.md)/[14-AI任务中心](./14-AI任务中心.md)。
