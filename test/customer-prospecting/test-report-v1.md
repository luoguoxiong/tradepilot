## 四、测试中发现的缺陷（已修复）

| 编号   | 级别       | 缺陷                                                                                  | 根因                                                                   | 修复                                                   |
| ------ | ---------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------ |
| BUG-01 | P1         | 联系人抽取错位：抓到 "Contact Max" 而非 "Max Weber"                                   | 正则 `[A-Z][a-z]+ [A-Z][a-z]+\b[^.]{0,40}?(职位词)` 惰性匹配到前缀词对 | 改为姓名紧邻职位词的前向断言（scraper.ts）             |
| BUG-02 | P2         | 报告 sources 只含 LLM 返回的首页，实际抓取的子页（含 /contact）未落库，违反可追溯验收 | queue 落库时未用抓取页面记录覆盖 LLM sources                           | sources 改为以实际抓取页面生成（label/url/fetched_at） |
| BUG-03 | P3（环境） | Node 18 下 cheerio 依赖的 undici 因缺 `File` 全局崩溃                                 | 运行时差异                                                             | 新增 polyfill.ts，在入口与 cheerio 引用处最先导入      |
