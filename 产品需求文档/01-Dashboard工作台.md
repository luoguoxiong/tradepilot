## 1. 模块定位

### 1.1 页面目标

让老板或业务员打开系统后快速知道：

- 今天 AI 做了什么
- 当前业务情况
- 高价值客户
- 风险和待处理事项

### 1.2 目标用户

- 外贸老板 / 外贸经理（看全局、看风险）
- 一线业务员（看待办、看客户）

### 1.3 核心组件

KPI Card、AI Employee Status、High Value Lead、Pending Tasks、AI Insight、Business Trend。

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 顶部问候与 AI 在线状态 | 显示问候语 + 「N 名员工在线」+ 日期；提供「AI 每日报告」入口 |
| FR-02 | KPI 卡片组 | 新客户 / 新询盘 / 新报价 / 预计成交额，均含数值与环比变化（↑x%） |
| FR-03 | AI 员工工作状态区 | 展示每个 AI 员工的状态色（全局语义色）、当前正在做的事、今日产出；提供「查看全部 AI 员工」跳转 |
| FR-04 | 高价值客户榜 | Top N 高价值客户 + 匹配/评分百分比，点击跳转客户 360° 详情 |
| FR-05 | 今日待处理事项 | 聚合四类提醒：报价待审核、高价值客户超期未联系、客户新回复、订单延期风险；每条可跳转对应模块处理 |
| FR-06 | 待办中心入口 | 「进入待办中心」统一处理全部待办 |

---

## 4. AI 行为边界

- 本页为**只读聚合视图**：AI 只负责汇总、统计与提醒，不在 Dashboard 上直接执行业务动作。
- 所有提醒必须可跳转到对应模块，由人工确认处理（与 AI 审核中心原则一致）。

## 5. 模块依赖

| 依赖模块 | 用途 |
|---|---|
| 02-AI数字员工中心 / 14-AI任务中心 | 员工在线状态、今日产出、待审核任务数 |
| 05-CRM客户中心 / 04-客户360° | 新客户数、高价值客户及评分 |
| 06-AI销售工作台 / 07-AI自动跟进 | 新询盘、客户新回复 |
| 09-报价中心 | 新报价数、待审核报价数 |
| 10-订单中心 | 预计成交额、延期风险订单 |

---

## 6. 效果指标（建议）

- Dashboard 日活打开率；「AI 每日报告」查看率。
- 今日待处理事项的**处理率**（点击处理后闭环的比例）。
- 从高价值客户榜进入客户详情的转化点击率。
