## 1. 页面区块与字段清单

### 1.1 AI 员工卡片（FR-01）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| employeeId | string | ✓ | 员工 ID |
| role | string | ✓ | 角色枚举：`lead_hunter` 获客 / `customer_researcher` 客户研究员 / `sales` 外贸销售员 / `follow_up` 跟进员工 / `merchandiser` 跟单员工 / `manager` 外贸经理 |
| name / avatar | string | ✓ | 名称 / 图标 |
| status | string | ✓ | employeeStatus 枚举（语义色） |
| statusDetail | string | — | 状态说明，如「正在处理 6 个询盘」 |
| todayStats | object[] | ✓ | 今日产出，`[{ label: "今日找到", count: 28, unit: "个客户" }]` |
| kpi | object | ✓ | `{ metric, achieved, target, progressPct }`，进度条数据源 |
| currentTaskId | string | — | 当前执行任务（联动 14-AI任务中心） |
| workspacePath | string | ✓ | 「进入工作台 →」跳转路由 |

### 1.2 创建 AI 员工表单（FR-03，按 §26 能力模型）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| role | string | ✓ | 角色枚举（决定可选模板） |
| name | string | ✓ | 员工名称 |
| goal | string | ✓ | 目标描述 |
| sopTemplateId | string | — | SOP 模板（按角色预置） |
| skills | string[] | ✓ | 技能标签 |
| tools | string[] | ✓ | 允许调用的工具：`web_search / site_crawl / email_send / crm_write / pricing_engine …` |
| knowledgeScope | string[] | ✓ | 可检索知识分类（11-知识中心 category 枚举） |
| memoryConfig | object | — | `{ retentionDays, scope }` |
| workflowId | string | — | 绑定工作流 |
| permissions | object | ✓ | 工具/数据权限白名单 |
| approvalPolicy | object | ✓ | `{ email_send: "always" | "high_value_only", quote: "always", autoExecute: [...] }`，高风险动作不可配置为免审批 |
| kpiConfig | object | ✓ | `{ metric, target, period }` |

> 校验：`approvalPolicy` 中 `quote / email_send / contract / order_change / bulk_marketing / customer_delete` 必须绑定审批，传 `none` 返回 `42201`（需求文档 16 §4）。

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/ai-employees` | 员工列表（含状态、今日产出、KPI） |
| POST | `/api/v1/ai-employees` | 创建 AI 员工 |
| GET | `/api/v1/ai-employees/{id}` | 员工详情（完整配置） |
| PUT | `/api/v1/ai-employees/{id}` | 更新配置 |
| GET | `/api/v1/ai-employees/{id}/tasks` | 该员工任务列表（复用 14 模块） |
| POST | `/api/v1/ai-employees/{id}/pause` | 暂停员工全部执行中任务 |
| POST | `/api/v1/ai-employees/{id}/resume` | 恢复 |
| GET | `/api/v1/ai-employees/roles` | 角色模板清单（含预置 SOP/Skills/Tools） |

## 3. 接口详细定义

### 3.1 GET /api/v1/ai-employees

响应 `data.items[]`：1.1 卡片字段。示例：

```json
{
  "items": [
    { "employeeId": "emp_1", "role": "lead_hunter", "name": "AI Lead Hunter",
      "status": "working", "statusDetail": "正在分析公司官网",
      "todayStats": [{ "label": "今日找到", "count": 28, "unit": "个客户" }],
      "kpi": { "metric": "daily_leads", "achieved": 28, "target": 35, "progressPct": 80 },
      "currentTaskId": "task_1001", "workspacePath": "/ai/lead-hunter" }
  ],
  "total": 6, "page": 1, "pageSize": 20
}
```

### 3.2 POST /api/v1/ai-employees

请求体：1.2 全部字段。响应：`{ employeeId }`。

错误：角色模板不含的工具返回 `42201`；权限不足（非 admin）返回 `40301`。

### 3.3 GET /api/v1/ai-employees/{id}/tasks

等价于 `GET /api/v1/tasks?employeeId={id}`（见 [14-AI任务中心](./14-AI任务中心.md)），返回该员工任务分页列表。

## 4. 联动与边界

- 本页为**管理视图**：仅展示与配置，不承载业务执行。
- 任务数据统一来自 14-AI任务中心；各员工工作台产出数据来自对应模块（03/04/06/07/10/13）。
- 创建/修改员工为高权限操作：`role ∈ {admin, manager}`，且写操作记入操作日志。
