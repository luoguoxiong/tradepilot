## 1. 产品定位

> **TradePilot AI —— Your 24/7 AI Foreign Trade Workforce**
> 让每一家外贸公司拥有自己的 AI 外贸团队。

让 AI 像真正的外贸员工一样，主动完成获客、客户研究、销售跟进、报价、订单协同与经营分析。

### 1.1 产品核心定位（§26、§27）

TradePilot AI 的核心**不是** `ChatGPT + CRM`，而是 **AI Employee Operating System**。

AI Employee 核心能力模型：

```text
AI Employee
│
├── Role        # 角色
├── Goal        # 目标
├── SOP         # 标准作业流程
├── Skills      # 技能
├── Tools       # 工具
├── Knowledge   # 知识
├── Memory      # 记忆
├── Tasks       # 任务
├── Workflow    # 工作流
├── Permissions # 权限
├── Approval    # 审批
└── KPI         # 绩效
```

### 1.2 产品核心原则（§25）：不是 AI Chat

错误形态（拒绝）：

```text
用户 → 聊天框 → AI 回答
```

正确形态（必须遵循）：

```text
用户 → 创建业务目标 → AI 创建任务 → AI 按 SOP 执行
     → 调用业务工具 → 产生业务结果 → 人工审核
```

## 6. MVP 用户主流程（§23）

```text
注册企业 → 上传产品资料 → 连接邮箱 → 创建 AI 获客任务
→ AI 寻找潜在客户 → AI 分析客户 → 客户评分 → 加入 CRM
→ AI 生成开发信 → 人工审核 → 发送 → AI 自动跟进
→ 客户回复 → AI 销售员协助成交
```

## 7. 页面设计规范（§24）

### Layout

- PC 优先：1440px
- 左侧导航：240px
- 顶部 Header：64px
- 内容最大宽度：1600px

### 页面结构

```text
Page Header
├── Title
├── Description
└── Primary Action

Filters

Main Content

Right AI Panel（可选）
```

### AI 状态颜色语义（全局统一）

```text
🟢 Working            # 执行中
🟡 Waiting Approval   # 等待审核
🔵 Scheduled          # 已排期
🔴 Risk / Failed      # 风险 / 失败
⚪ Idle               # 空闲
```
