## 1. 模块定位

### 1.1 页面目标

用户用自然语言下达获客目标，AI 数字员工自主完成「找客户 → 分析客户 → 评分」的全流程，产出可进入 CRM 的潜在客户列表。

### 1.2 核心工作流（§5.1）

```text
用户输入目标
      ↓
AI 解析市场与客户画像
      ↓
制定搜索策略
      ↓
发现潜在公司
      ↓
官网分析
      ↓
产品匹配
      ↓
客户评分
      ↓
联系人发现
      ↓
进入 CRM
```

## 3. 功能需求

### 3.1 AI 获客工作台

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 自然语言下达任务 | 左栏输入业务目标（如「帮我寻找美国做跑鞋的品牌，希望他们可能需要 Carbon Fiber Insoles」） |
| FR-02 | AI 自动优化目标 | 「✨ AI 自动优化目标」按钮，AI 补全/优化任务描述后再启动 |
| FR-03 | 任务启动与暂停 | 「开始任务」启动获客；顶部「⏸ 暂停」可中断执行 |
| FR-04 | 当前任务进度卡 | 任务目标、总进度百分比、发现数 / 目标数（如 28/35）、当前执行步骤 |
| FR-05 | AI 实时工作日志 | 按时间流展示执行过程：搜索 → 发现公司 → 读取官网 → 产品匹配度 → 发现联系人 → 查找公开联系方式；支持「查看全部执行日志」 |
| FR-06 | 今日产出汇总 | 头部展示：找到 N 家 / 分析 N 家 / 高价值 N 家 |

### 3.2 创建获客任务

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-07 | 自然语言输入 → AI 结构化解析 | AI 将目标解析为结构化字段：🌍 目标市场、🏢 客户类型、📦 目标产品、📊 公司规模 |
| FR-08 | 解析结果可编辑 | 用户可修正 AI 解析出的字段后再启动 |
| FR-09 | 高级设置 | 折叠面板，承载更细的筛选条件（具体字段待详细设计） |

### 3.3 客户发现列表

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-10 | 价值分层 Tab | 全部 / 🔥 高价值 / 🟡 中价值 / 低价值，各档显示数量 |
| FR-11 | 搜索与筛选 | 关键词搜索 + 国家 / 行业 / 匹配度筛选 |
| FR-12 | 列表字段 | 公司名、国家、匹配度进度条（百分比）、AI 评分等级（High/Medium）、[查看 →] 跳转客户 360° |
| FR-13 | 批量操作 | 多选 + 「批量加入 CRM」「批量分析」 |
| FR-14 | 分页 | 标准分页控件 |

## 4. AI 行为边界

- **评分与匹配度必须可解释**：客户评分 / 产品匹配度需能给出判断原因（联动客户 360° 的「AI 判断原因」），不允许只给数字。
- **联系人信息仅限公开商务渠道**：日志中的「查找公开商务联系方式」需遵守数据合规（GDPR/CCPA），禁止使用非公开/爬取的隐私数据。
- **加入 CRM 是状态变更动作**：单个或批量加入 CRM 需遵循操作权限；AI 不自动触发对外触达（开发信发送属于销售中心流程，且需人工审核）。
- 获客任务的执行边界受 AI 审核中心与任务审批策略约束。

## 6. 效果指标（建议）

- 获客产出量：每日发现客户数、高价值客户占比。
- 评分有效性：高价值客户后续回复率 / 转化率显著高于低价值档。
- 加入 CRM 转化率：发现列表 → CRM 的批量转化比例。
- AI 自动化率：无需人工干预完成的任务比例；暂停/纠偏次数。

## 7. 待澄清问题

1. 「高级设置」的具体字段（公司规模区间、年进口额、职衔过滤等）。
2. 客户评分模型口径：匹配度与 AI 评分（High/Medium）的关系与计算来源。
3. 重复客户判定：多次获客任务发现同一公司如何去重。
4. 每日获客量 / 外部数据源调用的成本上限设置。
