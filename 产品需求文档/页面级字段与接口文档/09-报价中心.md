## 1. 页面区块与字段清单

### 1.1 报价列表（FR-01～03）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| quoteId / quoteNo | string | ✓ | ID / 展示编号 `QT-20260904-001` |
| customerId / customerName | string | ✓ | 客户 |
| totalAmount / currency | string | ✓ | 金额（如 `"62500.00"` / `USD`） |
| status | string | ✓ | quoteStatus：`draft` 草稿 / `waiting_approval` 待审核 🟡 / `sent` 已发送 🟢 / `won` 已成交 / `lost` 已失效 |
| createdAt | string | ✓ | — |

Tab：`all / draft / waiting_approval / sent / won`（各档数量）。

### 1.2 报价详情 · 报价头（结构化，禁止自然语言含糊表述）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| quoteNo / status | string | ✓ | 同上 |
| customerId | string | ✓ | 客户 |
| currency | string | ✓ | 币种（ISO 4217） |
| incoterms | string | ✓ | 贸易条款：`FOB / CIF / EXW / DDP …` |
| validUntil | string | ✓ | Offer 有效期 |

| paymentTerms | string | ✓ | 付款条款（如 T/T 30% deposit） |

### 1.3 明细行（FR-02）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| productId / productName | string | ✓ | 产品 |
| quantity | number | ✓ | 数量 |

### 1.4 AI 定价建议（FR-04，Insight Schema）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| suggestedUnitPrice | string | ✓ | 推荐单价（定价引擎输出，非 LLM 生成） |

## 3. 接口详细定义

### 3.1 POST /api/v1/quotes

请求：

```json
{ "customerId": "cus_1", "currency": "USD", "incoterms": "FOB",
  "validUntil": "2026-09-30", "paymentTerms": "T/T 30% deposit",
  "items": [ { "productId": "prod_1", "quantity": 5000, "unitPrice": "12.50" } ] }
```

响应：`{ quoteId, quoteNo: "QT-20260904-001", status: "draft" }`。
校验：`quantity < MOQ` 返回 `42201`；`validUntil <= 今天` 返回 `42201`。

### 3.2 POST /api/v1/quotes/{id}/ai-pricing

响应 `data`：

```json
{
  "suggestedUnitPrice": "12.50", "profitMarginPct": 32,
  "costBreakdown": { "purchase": "8.00", "freight": "0.80", "insurance": "0.10", "tax": "0.30", "fx": "0.20" },
  "reasons": [
    { "text": "采购数量较大", "evidence": "5,000 pairs ≥ 价格档 5,000+", "source": "pricing_engine" },
    { "text": "客户评分高", "evidence": "Score 92", "source": "crm" },
    { "text": "历史成交价格在合理范围", "evidence": "近 90 天同产品成交 $12.3~$13.1", "source": "history" } ]
}
```

服务端校验：`unitPrice` 低于利润红线时拒绝保存/提交，返回 `42201`（利润红线 100% 拦截）。

### 3.3 POST /api/v1/quotes/{id}/submit

响应：

```json
{ "quoteId": "quote_9", "status": "waiting_approval",
  "approval": { "approvalId": "appr_30", "approvalType": "quote", "riskLevel": "high", "status": "pending" } }
```

### 3.4 POST /api/v1/quotes/{id}/send

前置校验：关联审批 `status ∈ approved/edited_approved`，否则 `40901`。
响应：`{ status: "sent", sentAt }`（走 16-系统设置邮箱通道外发，并写入客户活动）。

### 3.5 POST /api/v1/quotes/{id}/mark-won 与转订单

- `mark-won`：`{ status: "won" }`，写入客户 360° Quotes。
- `POST /api/v1/orders/from-quote`：请求 `{ quoteId }` → 响应 `{ orderId, orderNo }`（见 [10-订单中心](./10-订单中心.md)）。

## 4. 联动与边界

- **价格数字不许 LLM 自由生成**：`ai-pricing` 由结构化定价引擎（成本 + 报价规则 + 历史成交）输出，AI 仅负责 `reasons` 表达。
- **报价具有法律效力**：`validUntil/incoterms/currency/exchangeRate/paymentTerms` 为必填结构化字段。
- 状态机：`draft → waiting_approval → sent → won`；编辑仅限 `draft`；`sent/won` 不可改（`40901`）。
- 多轮议价：让价梯度建议（3%→2%→1% 递减）由定价规则配置（16-系统设置）提供，接口预留 `GET /api/v1/quotes/{id}/negotiation-ladder`。
- 客户信息与评分来自 [05-CRM客户中心](./05-CRM客户中心.md)；审核流转见 [12-AI审核中心](./12-AI审核中心.md)。
