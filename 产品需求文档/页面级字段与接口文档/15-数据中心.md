# 15 · 数据中心 · 页面字段与接口

| 项 | 内容 |
|---|---|
| 对应需求文档 | [15-数据中心](../15-数据中心.md) |
| 版本 | v0.1（2026-09-04） |
| 页面 | 数据分析看板（筛选 + 趋势图 + 市场分布 + AI 贡献） |

---

## 1. 页面区块与字段清单

### 1.1 全局筛选（FR-01）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| period | string | ✓ | `this_week / this_month / custom`（custom 附 startDate/endDate） |
| country | string | — | 市场筛选，默认 `all` |
| employeeId | string | — | AI 员工筛选，默认 `all` |

### 1.2 客户增长趋势图（FR-02）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| date | string | ✓ | 时间点（天） |
| newCustomers | number | ✓ | 新客户数 |
| newInquiries / newQuotes | number | — | 可选叠加序列 |

### 1.3 市场分布（FR-03）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| country | string | ✓ | 国家（USA / Germany / UK / Other） |
| customerCount | number | ✓ | 客户数 |
| pct | number | ✓ | 占比（45% / 25% / 18% / 12%） |

### 1.4 AI 贡献（FR-04）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| foundCustomers | number | ✓ | AI 找到客户：328 |
| repliedEmails | number | ✓ | AI 回复邮件：86 |
| savedHours | number | ✓ | AI 节省工时：42h（**估算指标，页面标注口径说明**） |
| promotedInquiries | number | ✓ | AI 促成询盘：18（归因规则待澄清） |
| caliberNote | string | ✓ | 指标口径说明文案 |

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/analytics/customer-trend` | 客户增长趋势 |
| GET | `/api/v1/analytics/market-distribution` | 市场分布 |
| GET | `/api/v1/analytics/ai-contribution` | AI 贡献 |
| GET | `/api/v1/analytics/drilldown` | 指标下钻明细（FR-05） |
| GET | `/api/v1/analytics/export` | 导出（Excel/PDF，可选） |

> 全部接口共用 1.1 筛选参数：`period, startDate, endDate, country, employeeId`。

---

## 3. 接口详细定义

### 3.1 GET /api/v1/analytics/customer-trend

响应 `data`：

```json
{ "trend": [ { "date": "2026-08-29", "newCustomers": 3 }, { "date": "2026-08-30", "newCustomers": 5 } ] }
```

### 3.2 GET /api/v1/analytics/market-distribution

响应 `data`：

```json
{ "markets": [ { "country": "US", "customerCount": 148, "pct": 45 },
               { "country": "DE", "customerCount": 82, "pct": 25 },
               { "country": "UK", "customerCount": 59, "pct": 18 },
               { "country": "OTHER", "customerCount": 39, "pct": 12 } ] }
```

### 3.3 GET /api/v1/analytics/ai-contribution

响应 `data`：

```json
{ "foundCustomers": 328, "repliedEmails": 86, "savedHours": 42, "promotedInquiries": 18,
  "caliberNote": "节省工时=AI 自动完成动作数 × 单动作人工基准时长（估算）" }
```

### 3.4 GET /api/v1/analytics/drilldown

请求参数：公共筛选 + `metric(new_customers|inquiries|found_customers|replied_emails|…)`、分页。
响应：对应明细列表（如客户明细 `items[] = 客户列表行字段`），用于「统计口径必须可下钻验证」。

---

## 4. 联动与边界

- 「AI 节省工时」为估算指标，`caliberNote` 必须随接口返回并在页面展示，避免夸大 ROI。
- 统计口径与业务明细一致：所有数字必须能通过 `drilldown` 下钻验证；AI 不输出无数据支撑的结论。
- 数据权限：经理看团队（`scope=team`）、业务员只看自己（`scope=self`），见 [00-总览 §4.4](./00-总览与接口规范.md)。
- 本模块统计被 [13-AI外贸经理](./13-AI外贸经理.md) 经营分析复用（同源接口）。
