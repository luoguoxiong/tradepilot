## 1. 模块定位

### 1.1 页面目标

管理报价全生命周期（创建 → AI 定价建议 → 人工审核 → 发送 → 成交），AI 提供定价建议与理由，**最终价格由人工确认**。

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 状态流转 | 全部 / 草稿 / 待审核 / 已发送 / 已成交；状态机：草稿 → 待审核 → 已发送 → 已成交 |
| FR-02 | 新建报价 | 「+ 新建报价」；选择客户与产品，录入数量生成明细行（产品 / 数量 / 单价 / 总价） |
| FR-03 | 报价单编号 | 规则形如 `QT-20260904-001`（日期 + 序列） |
| FR-04 | AI 定价建议 | 推荐价格、利润率、**推荐原因（数量、客户评分、历史成交价等证据，必须展示）** |
| FR-05 | 编辑报价 | 用户可修改价格与明细后再提交 |
| FR-06 | 提交审核 | 「提交审核 →」进入 AI 审核中心（报价为审核类型，High Risk） |
| FR-07 | 发送与成交 | 审核通过后发送给客户（联动销售中心邮箱）；客户接受后标记成交并转订单 |

## 4. AI 行为边界

- **价格数字不许 LLM 自由生成**：推荐价必须来自结构化定价引擎（成本 + 报价规则 + 历史成交数据），AI 只负责解释与表达；利润率必须可核算（售价 - 采购成本 - 运费 - 保费 - 税费 - 汇兑）。
- **报价具有法律效力**：Offer 有效期、币种、汇率时点、Incoterms 必须为结构化字段，不允许自然语言含糊表述。
- 最终价格与发送动作必须人工审核批准（AI 审核中心 High Risk 类型）。
- 多轮议价：AI 可建议让价梯度（如 3% → 2% → 1% 递减），不得直接暴露底价（待详细设计确认）。

## 6. 效果指标（建议）

- AI 定价建议采纳率（人工未改价直接通过的比例）。
- 报价到成交转化率、平均报价响应时长。
- 利润红线命中率：低于利润红线的报价被拦截数（应为 100% 拦截）。
