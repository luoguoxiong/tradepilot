## 2. 全局接口约定

### 2.1 基础约定

| 项 | 约定 |
|---|---|
| Base URL | `/api/v1` |
| 协议 | HTTPS + JSON（UTF-8） |
| 认证 | `Authorization: Bearer <JWT>`，JWT 内含 `userId / orgId / role` |
| 租户隔离 | 全部资源按 `orgId` 隔离，由服务端从 Token 解出，接口不传 orgId |
| 时间 | ISO 8601 UTC：`2026-09-04T14:32:00Z`；前端按本地时区渲染 |
| 金额 | 金额一律 `amount`（字符串十进制，如 `"12500.00"`）+ `currency`（ISO 4217，默认 `USD`） |
| 多语言 | 请求头 `Accept-Language`；AI 生成内容带 `language` 字段 |

### 2.2 统一响应结构

```json
{ "code": 0, "message": "ok", "data": { }, "traceId": "trc_xxx" }
```

- `code = 0` 成功；非 0 见 §2.5 错误码。
- 列表接口 `data` 固定为分页对象：

```json
{ "items": [ ], "total": 128, "page": 1, "pageSize": 20 }
```

### 2.3 分页 / 排序 / 筛选

| 参数 | 说明 |
|---|---|
| `page` | 页码，从 1 开始，默认 1 |
| `pageSize` | 每页条数，默认 20，最大 100 |
| `keyword` | 关键字搜索（各接口声明匹配字段） |
| `sortBy` / `sortOrder` | 排序字段 / `asc\|desc`，默认按创建时间倒序 |

### 2.4 ID 规范

内部 ID 使用「前缀 + 雪花 ID」，展示编号（业务单号）独立字段：

| 资源 | 内部 ID 前缀 | 展示编号 |
|---|---|---|
| AI 员工 | `emp_` | — |
| 任务 | `task_` | — |
| 发现客户（Lead） | `lead_` | — |
| 客户 | `cus_` | — |
| 联系人 | `con_` | — |
| 会话 / 消息 | `conv_` / `msg_` | — |
| 产品 | `prod_` | SKU（如 `CF-001`） |
| 报价 | `quote_` | `QT-20260904-001`（quoteNo） |
| 订单 | `order_` | `SO-20260904-001`（orderNo） |
| 知识文档 | `doc_` | — |
| 审批 | `appr_` | — |
| 跟进策略 / 跟进任务 | `strat_` / `ftask_` | — |
| 经营报告 | `rpt_` | — |

### 2.5 错误码

| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数错误 |
| 40101 | 401 | 未认证 / Token 失效 |
| 40301 | 403 | 无权限（含数据范围限制） |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 状态冲突（如重复提交、非法状态流转） |
| 42201 | 422 | 业务校验失败（如报价低于利润红线） |
| 42901 | 429 | 频率限制 |
| 50001 | 500 | 服务内部错误 |
| 50301 | 503 | 依赖服务不可用（LLM / 邮箱 / 外部数据源） |

## 4. AI 产出与高风险动作的接口约束

> 对应各需求文档「AI 行为边界」，以下约束在接口层强制体现。

### 4.1 AI 产出结构（Insight Schema）

凡是 AI 生成结论（评分、概率、建议、风险、定价），字段必须携带证据链与置信度：

```json
{
  "value": 92,                    // 结论值（评分/百分比等）
  "confidence": 0.92,             // 置信度 0~1
  "reasons": [                    // 判断原因，逐条证据，禁止虚构
    { "text": "产品高度匹配", "evidence": "官网产品线含 Running Shoes", "source": "web_crawl" }
  ],
  "citations": [                  // 知识库引用（可追溯）
    { "docId": "doc_1", "docName": "Carbon Fiber Catalog.pdf", "chunkId": "chk_88" }
  ],
  "generatedAt": "2026-09-04T14:35:00Z"
}
```

### 4.2 高风险动作必须走审批

报价提交、邮件外发、订单变更、客户删除、批量营销等接口：

- 受企业审批策略约束，服务端判定后返回 `approvalRequired: true` 与 `approvalId`，业务对象状态置为 `waiting_approval`；
- 审批通过前接口拒绝实际执行（`40901`）；
- 审批处置接口见 [12-AI审核中心](./12-AI审核中心.md)。

### 4.3 异步任务模式

AI 长耗时操作（获客执行、AI 分析、报告生成、知识索引）：

1. 触发接口返回 HTTP 200 + `taskId`（任务状态 `running/scheduled`）；
2. 进度与结果通过任务接口获取：`GET /tasks/{taskId}`、日志 `GET /tasks/{taskId}/logs`、实时流 `GET /tasks/{taskId}/stream`（SSE）；
3. 任务模型与状态机统一由 [14-AI任务中心](./14-AI任务中心.md) 定义，各业务模块复用。

### 4.4 数据权限

- 客户/订单/报价等资源带 `ownerId`；业务员默认仅可见本人资源，经理/管理员可见团队/全部；
- 列表接口支持 `scope=self | team | all`（默认按角色上限裁剪，越权返回 `40301`）；
- 审批、AI 员工配置、系统设置仅限 `admin/manager`（见 16-系统设置权限模型）。
