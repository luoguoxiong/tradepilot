## 1. 页面区块与字段清单

### 1.1 登录 / 注册（FR-01，P0）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| email / password | string | ✓ | 登录凭据（MVP 仅邮箱+密码；验证码/企微扫码列 P1，请求预留 `loginType` 扩展字段，16 需求 §3.3 FR-01） |
| companyName | string | ✓ | 注册：企业名称 |
| contactName / email / password | string | ✓ | 注册：管理员信息 |

### 1.2 企业初始化向导（FR-01，P0，对应 MVP 主流程 §23）

| 步骤 | 动作 | 联动接口 |
|---|---|---|
| 1. 注册企业 | 创建组织与管理员 | `POST /auth/register` |
| 2. 上传产品资料 | 知识入库/产品创建 | `POST /knowledge/documents`、`POST /products` |
| 3. 连接邮箱 | 收发通道 | `POST /settings/mailboxes` |
| 4. 完成 | 引导创建首个获客任务 | `POST /lead-tasks` |

向导状态字段：`{ currentStep: 1-4, steps: [{ key, done }] }`。

### 1.3 企业信息（FR-02）

`orgName*、logo、country、timezone*、defaultLanguage*、defaultCurrency*、industry、sendRules`（外发规则：`{ sendWindow: { start, end }, minTouchIntervalDays }`，16 FR-12 / 07 §7）

> **区域与本地化**（16 需求 v0.4 §3.3 FR-02）：`timezone`（IANA，默认 `Asia/Shanghai`）为 07 发送窗口 / 14 定时任务 / 13 报告周期统一基准；`defaultCurrency`（默认 `USD`）为 09 新报价默认币种；`defaultLanguage`（默认 `zh-CN`，MVP 支持 `zh-CN / en`）为界面语言。仅管理员可编辑；`timezone` 变更仅对新排期生效。ER 01 v0.2 已有对应列，无 DDL 变更。

## 3. 接口详细定义

### 3.1 POST /api/v1/auth/register

请求：`{ companyName, contactName, email, password }`
响应：`{ token, user: { userId, orgId, role: "admin" } }`；同时初始化默认角色权限、默认跟进策略、6 个预置 AI 员工。

### 3.2 POST /api/v1/auth/login

请求：`{ email, password }` → 响应：`{ token, expiresIn, onboarding: { currentStep } }`（未完成初始化时前端进向导）。

### 3.3 POST /api/v1/settings/mailboxes

请求：

```json
{ "provider": "smtp_imap", "account": "sales@company.com",
  "imap": { "host": "imap.company.com", "port": 993, "ssl": true, "credential": "***" },
  "smtp": { "host": "smtp.company.com", "port": 465, "ssl": true, "credential": "***" },
  "syncScope": { "historyDays": 90, "folders": ["INBOX", "Sent"] } }
```

响应：`{ mailboxId, status: "connected" }`。
边界：`credential` 加密存储；响应与详情接口**永不回显明文凭据**（脱敏 `sales***@company.com`）。

### 3.4 POST /api/v1/settings/mailboxes/{id}/test

响应：`{ ok: true, imap: "ok", smtp: "ok" }` 或 `{ ok: false, error: "SMTP auth failed" }`。

### 3.5 PUT /api/v1/settings/pricing-rules

请求：1.6 字段。校验：`profitFloorPct` 修改后立即对报价提交生效（服务端 100% 拦截）。

### 3.6 PUT /api/v1/settings/roles/{role}/permissions

校验（需求文档 §4）：`approvalPolicy` 类强制项——`quote/email_send/contract/order_change/bulk_marketing/customer_delete` 的审批绑定**不可被配置绕过**，传 `none` 返回 `42201`。

## 4. 联动与边界

- **基座模块**：邮箱通道供 06/07 外发；权限模型约束所有接口（`00-总览 §4.4`）；审批人配置供 12 使用；模型配置供全部 AI 员工使用。
- AI 员工配置（FR-04）复用 [02-AI数字员工中心](./02-AI数字员工中心.md) 的 `/ai-employees` 接口。
- 初始化完成率指标：`GET /org/onboarding` 记录各步骤完成时间，支撑「注册 → 连接邮箱 → 首个获客任务」漏斗统计。
- 登录方式已澄清（16 需求 v0.4 §7.3）：MVP 仅邮箱+密码，登录接口预留 `loginType` 扩展字段（验证码 / 企业微信扫码 P1）；区域与本地化 3 默认值（timezone / defaultCurrency / defaultLanguage）已纳入 `GET/PUT /org`。
