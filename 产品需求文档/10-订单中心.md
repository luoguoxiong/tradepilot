## 1. 模块定位

### 1.1 页面目标

管理订单履约全流程（下单 → 付款 → 生产 → 发货 → 完成），AI 持续监控订单进度并提前预警延期风险，给出处理建议。

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 状态筛选 | 全部 / 待付款 / 生产中 / 待发货 / 已完成 |
| FR-02 | 创建订单 | 「+ 创建订单」；支持从已成交报价转化 |
| FR-03 | 订单编号 | 规则形如 `SO-20260904-001` |
| FR-04 | 列表字段 | 订单号、客户、交期、状态、风险（🟢 正常 / 🔴 延期风险） |
| FR-05 | 订单详情 | 客户、金额、交期；订单进度条：PO Confirmed → Payment → Production（百分比）→ Shipping |
| FR-06 | AI 风险分析 | 预计延期天数、**原因（如生产进度低于计划）**、建议动作清单（联系生产负责人 / 调整生产计划 / 准备客户沟通邮件） |
| FR-07 | 处理入口 | 「AI 执行建议」按清单执行（可执行项进入任务/审核流程）；「人工处理」转人工跟进 |
| FR-08 | 客户沟通联动 | 「准备客户沟通邮件」联动销售工作台生成延期沟通草稿 |

---

## 4. AI 行为边界

- **延期预警必须给出可核查的原因**，不允许无依据的风险标记。
- 「AI 执行建议」中涉及对客户的承诺（新交期、赔偿）必须人工审核后发出；对内动作（联系生产负责人）可按权限自动化。
- 订单变更为 AI 审核中心的高危审核类型，AI 不得擅自修改订单金额 / 交期 / 数量。
- AI 无法真实预测汇率走势与绝对交期，产出为基于计划进度的**估算**，需标注为估算值。

## 6. 效果指标（建议）

- 延期预警提前量：风险标记早于实际延期的天数。
- 预警准确率：标记风险的订单中真实延期的比例。
- 延期订单客户沟通及时率（延期订单 100% 主动沟通）。
