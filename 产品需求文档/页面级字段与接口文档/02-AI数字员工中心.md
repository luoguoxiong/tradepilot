## 1. 页面区块与字段清单

### 1.1 AI 员工卡片（FR-01）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| employeeId | string | ✓ | 员工 ID |
| role | string | ✓ | 角色枚举：`lead_hunter` 获客 / `customer_researcher` 客户研究员 / `sales` 外贸销售员 / `follow_up` 跟进员工 / `merchandiser` 跟单员工 / `manager` 外贸经理 |
| name / avatar | string | ✓ | 名称 / 图标 |
| status | string | ✓ | employeeStatus 枚举（语义色）；跟单员工 P0 固定返回 `idle`（需求 02 §1.2 v0.3，不新增枚举值） |
| statusDetail | string | — | 状态说明，如「正在处理 6 个询盘」；跟单员工占位返回「即将上线，随订单中心（P1）启用」 |
| todayStats | object[] | ✓ | 今日产出，`[{ label: "今日找到", count: 28, unit: "个客户" }]` |
| kpi | object | 条件 | `{ metric, achieved, target, progressPct }`，进度条数据源；metric 按角色枚举（见下方注）；跟单员工占位期返回 `null` |
| currentTask | object | — | 当前执行任务**轻量对象**（v0.2.1）：`{ taskId, title, taskType, status, progressPct, currentStep }`，服务端只读聚合自 `ai_task` 单行（取该员工最新一条非终态任务），**不依赖 14-AI任务中心接口**；无进行中任务返回 `null`；完整任务列表 / 日志 / 重试恢复操作随 14（P1，需求 02 FR-04） |
| workspacePath | string | 条件 | 「进入工作台 →」跳转路由；P0 阶段跟单员工返回 `null`，前端渲染禁用态入口 |

> **kpi.metric 角色枚举（需求 02 §3.2）**：`lead_hunter=daily_leads` / `customer_researcher=daily_profiles` / `sales=daily_replies` / `follow_up=daily_followups` / `merchandiser=active_orders`（P1 启用）/ `manager=daily_reports`；`period` 固定 `daily`。

### 1.2 创建 AI 员工表单（FR-03，按 §26 能力模型）

> **分步向导（需求 02 §3.1 v0.2）**：前端按 4 步采集——① `role` → ② `name / goal / sopTemplateId / sopParams` → ③ `skills / tools / knowledgeScope / memoryConfig / workflowId` → ④ `permissions / approvalPolicy / kpiConfig`。角色模板（`GET /roles`）预填 ②-④；**仅前端分步，后端单次 POST 提交**。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| role | string | ✓ | 角色枚举（决定可选模板与 KPI metric） |
| name | string | ✓ | 员工名称 |
| goal | string | ✓ | 目标描述 |
| sopTemplateId | string | — | SOP 模板（按角色预置预填）；MVP 不开放 `content` 结构/富文本编辑（需求 02 §3.1 v0.3） |
| sopParams | object | — | SOP 高级设置参数级微调：仅允许角色模板定义的参数键（如 `match_product` 分档阈值，默认 High ≥ 85，见 LangGraph 工作流 00）；传入时后端基于预置模板派生 org 级副本（`sop_template.is_preset=false`）并绑定 |
| skills | string[] | ✓ | 技能标签 |
| tools | string[] | ✓ | 允许调用的工具：`web_search / site_crawl / email_send / crm_write / pricing_engine …` |
| knowledgeScope | string[] | ✓ | 可检索知识分类（11-知识中心 category 枚举） |
| memoryConfig | object | — | `{ retentionDays, scope }` |
| workflowId | string | — | 绑定工作流 |
| permissions | object | ✓ | 工具/数据权限白名单 |
| approvalPolicy | object | ✓ | `{ email_send: "always" | "high_value_only", quote: "always", autoExecute: [...] }`，高风险动作不可配置为免审批 |
| kpiConfig | object | ✓ | `{ metric, target, period }`；metric 按角色枚举（1.1 注）、period 固定 `daily`；target 由角色模板预填建议值可改（初始建议见需求 02 §3.2 v0.3） |

> 校验：`approvalPolicy` 中 `quote / email_send / contract / order_change / bulk_marketing / customer_delete` 必须绑定审批，传 `none` 返回 `42201`（需求文档 16 §4）。

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/ai-employees` | 员工列表（含状态、今日产出、KPI） |
| POST | `/api/v1/ai-employees` | 创建 AI 员工 |
| GET | `/api/v1/ai-employees/{id}` | 员工详情（完整配置） |
| PUT | `/api/v1/ai-employees/{id}` | 更新配置 |
| GET | `/api/v1/ai-employees/{id}/tasks` | 该员工任务列表（复用 14 模块） |
| POST | `/api/v1/ai-employees/{id}/pause` | 暂停员工全部执行中任务 |
| POST | `/api/v1/ai-employees/{id}/resume` | 恢复 |
| GET | `/api/v1/ai-employees/roles` | 角色模板清单（预置 SOP/Skills/Tools + KPI 建议值 + SOP 高级设置参数定义，v0.2） |

## 3. 接口详细定义

### 3.1 GET /api/v1/ai-employees

响应 `data.items[]`：1.1 卡片字段。示例：

```json
{
  "items": [
    { "employeeId": "emp_1", "role": "lead_hunter", "name": "AI Lead Hunter",
      "status": "working", "statusDetail": "正在分析公司官网",
      "todayStats": [{ "label": "今日找到", "count": 28, "unit": "个客户" }],
      "kpi": { "metric": "daily_leads", "achieved": 28, "target": 35, "progressPct": 80 },
      "currentTask": { "taskId": "task_1001", "title": "寻找美国跑鞋品牌", "taskType": "lead_hunting",
                       "status": "running", "progressPct": 60, "currentStep": "match_product" },
      "workspacePath": "/ai/lead-hunter" },
    { "employeeId": "emp_6", "role": "merchandiser", "name": "AI 跟单员工",
      "status": "idle", "statusDetail": "即将上线，随订单中心（P1）启用",
      "todayStats": [], "kpi": null, "currentTask": null, "workspacePath": null }
  ],
  "total": 6, "page": 1, "pageSize": 20
}
```

### 3.2 POST /api/v1/ai-employees

请求体：1.2 全部字段。响应：`{ employeeId }`。

错误：角色模板不含的工具返回 `42201`；`kpiConfig.metric` 与 `role` 不匹配返回 `42201`；`sopParams` 含模板未定义的参数键返回 `42201`；权限不足（非 admin/manager）返回 `40301`。

### 3.3 GET /api/v1/ai-employees/{id}/tasks

等价于 `GET /api/v1/tasks?employeeId={id}`（见 [14-AI任务中心](./14-AI任务中心.md)），返回该员工任务分页列表。

## 4. 联动与边界

- 本页为**管理视图**：仅展示与配置，不承载业务执行。
- 6 员工卡片全量返回（需求 02 §1.2 v0.2）；跟单员工 P0 为占位（`idle` + 「即将上线」+ `workspacePath=null`），随订单中心（P1）启用后返回真实数据。
- 任务数据统一来自 14-AI任务中心；各员工工作台产出数据来自对应模块（03/04/06/07/10/13）。
- 创建/修改员工为高权限操作：`role ∈ {admin, manager}`，且写操作记入操作日志。
