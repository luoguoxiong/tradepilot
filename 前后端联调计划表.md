## 3. 联调执行约定

1. **切真窗口开关**：单模块联调开始时按模块在本地 `VITE_USE_MOCK=false` + proxy 指向 staging/本地后端；未联调模块继续走 mock，避免一次全量切换阻塞多路并行。
2. **契约护栏**：后端接口与接口文档不一致时，遵循「mock 即契约」——先在 MSW handler/契约测试（`web/src/mocks`、`tests/contract`）上暴露漂移，再与后端确认文档先行、同步前端类型（`web/src/api/types`）。
3. **记录与闭环**：每行联调产出在对应 PR 描述或缺陷单登记；阻塞项在表末「是否完成」标 ⛔ 并注明阻塞点与负责人，解阻后置 ✅。
4. **双周节奏**：每双周五复盘一次本表，更新状态列并同步修订两个排期文档；联调不占用里程碑出口判定。
5. **已知风险**：真实 SSE 流、审批新鲜度校验、时区窗口、Gmail OAuth 审核周期为本计划最大变量，遇阻优先按后端排期 §5 对策兜底。
