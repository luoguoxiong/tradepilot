## 1. Design Tokens

`styles/tokens.scss` 定义 CSS Variables，Element Plus 主题经 `element-overrides.scss` 对齐同一套变量。

### 1.1 AI 状态语义色（全局统一，[产品总览 §7](../产品需求文档/00-产品总览与MVP规划.md)）

| Token | 语义 | 应用 |
|---|---|---|
| `--ai-working` | 🟢 执行中 | 员工状态、任务 running |
| `--ai-waiting` | 🟡 等待审核 | waiting_approval、审批角标 |
| `--ai-scheduled` | 🔵 已排期 | scheduled、new_lead 阶段 |
| `--ai-risk` | 🔴 风险/失败 | risk / failed、cold 阶段、延期风险 |
| `--ai-idle` | ⚪ 空闲 | idle 状态 |

### 1.2 其他色板

- 风险等级：`high` 红 / `medium` 橙 / `low` 灰蓝（12 §7.1 风险分流口径）；
- 客户阶段：`new_lead` 🔵 / `contacted` 🟡 / `negotiation` 🟢 / `cold` 🔴（接口规范 §3.3）；
- 布局：Header 64px / Sider 240px / 内容最大 1600px / 基准字号 14px / 圆角 8px / 间距 4 的倍数。

## 2. 业务组件清单（components/business）

### 2.1 InsightCard —— AI 产出证据链展示（全应用最核心组件）

凡 AI 生成结论（评分/概率/建议/风险）一律用此组件呈现[接口规范 §4.1 Insight Schema](../产品需求文档/页面级字段与接口文档/00-总览与接口规范.md)：

```text
┌───────────────────────────────────────────┐
│ 采购概率 92%          confidence 92% ▓▓▓▓░ │
│ 判断原因（逐条）                            │
│  • 产品高度匹配 —— 官网产品线含 Running     │
│    Shoes（来源：web_crawl）                 │
│ 知识引用 [Carbon Fiber Catalog.pdf] [×2]   │ ← citations 可点击
│ 分析于 2026-09-04 22:35 · ⚠ estimated 标记 │
└───────────────────────────────────────────┘
```

- Props：`{ value, valueLabel?, confidence, reasons[], citations[], estimated?, generatedAt }`；
- confidence 视觉分级：≥0.8 实色 / 0.5~0.8 半透明 / <0.5 灰 + 「低置信」角标；
- citations 点击 → `CitationPopover`：展示 docName/分类/上传人；软删文档标记「已删除」并禁再跳转（P1-5 留痕口径）；
- `estimated: true` 强制角标（业务报告约束）。

## 3. 关键页面实现模式

### 3.1 Dashboard（01）

- 单聚合接口 `GET /dashboard/summary` 一次拉取；区块级 `v-if` 按**返回字段存在性**渲染（D1/D2，不读 0 值）；
- KPI 卡组件化：`{ label, value, trend?, metric }`，卡片数自适应 grid；
- 今日待处理项：点击直接路由到对应模块并携带预置筛选（如审批中心对应 Tab）。

### 3.2 AI 销售工作台（06）—— 三栏布局

```text
┌──────────┬──────────────────────┬───────────────┐
│ 客户/会话 │  会话消息（邮件线程）  │ AI Copilot    │
│ 双层列表  │  虚拟滚动，按日期分组  │  意图/概率/阶段 │
│ 优先级+   │  消息气泡 + 展开引用   │  InsightCard  │
│ 未读态    │  ┌────────────────┐ │  推荐动作列表   │
│          │  │ DraftEditor     │ │  （D8 过滤）   │
│          │  │ + 发送/存草稿    │ │  citations    │
└──────────┴──┴─────────────────┴─┴───────────────┘
```

- 三栏宽度可拖拽（`Splitpanes` 自研轻实现），布局比例本地持久化；
- 会话列表/消息接口分页：向上滚动加载历史（`keepPreviousData` 防抖动）；
- **DraftEditor** 语义：
  - 空态 + `insert_draft`：AI 草稿一键填入（内容型建议合并入口，工程约定）；
  - 编辑后批准：审批流「编辑后批准」跳转本编辑器预填 `aiProposal`，提交走编辑批准接口；
  - 工具条：插入知识引用（从 11 检索）、变量占位、多语言拼写（按会话 detectedLanguage 提示）；
  - 渲染消毒：所有 AI/邮件 HTML 经 DOMPurify 白名单注入。
- 发送动作：提交后若返回 `approvalRequired: true + approvalId` → 消息区该条置「等待审核」态并提示（接口规范 §4.2）。

### 3.3 AI 获客（03）

- 创建任务：自然语言输入（textarea）+ 结构化补充字段（地区/行业/数量），提交得 `taskId`；
- 任务执行中：`TaskProgressCard + StreamLogPanel` 常驻工作台；`done` 后自动刷新发现列表并 toast；
- 发现列表：Tab（全部/高价值/已加入 CRM）、匹配度与 AI 评分列（InsightCard 简态：hover 展开完整 reasons）、行内「加入 CRM」；
- 批量加入 CRM：走批量接口，成功行转「已转化」态；`40301`（他人资源）行级报错。

### 3.4 AI 审核中心（12）

- 分类 Tab = 实际有数的 approvalType（D10）；列表卡片 `ApprovalCard`：
  - 头部：type 标签 + riskLevel + 剩余时限（expires_at 倒计时，超时置「已过期」终态禁用按钮）；
  - 内容：`context`（业务上下文摘要）+ `aiProposal`（邮件类预览正文、报价类表格）+ InsightCard 简态；
- 三态处置：
  - **批准**：二次确认弹窗（高风险类型确认文案不同）；
  - **编辑后批准**：跳 DraftEditor / 对应编辑器，回填 `aiProposal`，提交编辑批准接口；
  - **拒绝**：必填拒绝理由（弹窗表单）；
- 处置成功：乐观移除 + invalidate 队列与待审数（notifyStore 联动 Header 铃标）。

### 3.5 AI 自动跟进（07）

- 策略表单（最复杂表单，约 5 组字段）：
  - 适用范围（客户阶段/价值分层多选）、自动发送策略（逐条审/自动发送按 12 规则）、
    跟进节奏（节奏数组编辑器：`第 N 天 + 动作` 行编辑，可增删排序）、内容（模板选择或内联编辑）、启用开关；
  - 节奏行编辑器为自定义子表单组件 `RhythmEditor`（校验天数递增）；
- 跟进任务列表：状态 Tab（ready/scheduled/waiting_approval/completed/paused）+ `next_run_at` 按企业时区展示；
- 策略应用：列表行「应用到客户」（单选/批量），调用 `POST /follow-up-strategies/{id}/apply`；
- 默认策略：种子数据标记「默认」不可删，仅可复制编辑（UI 禁用删除按钮）。

### 3.6 知识中心（11）

- 列表：分类 Tab + 状态列（indexed/indexing/failed，failed 显示重试按钮）；
- 上传：`Uploader` 批量上传 → 返回 docId 列表进入索引中态 → 轮询索引状态（3s，至终态）；
- 软删：删除二次确认文案注明「文档与检索内容将删除，历史引用保留回溯信息」；删除后列表即时移除（invalidate）；
- 检索预览（AI 引用测试）：输入问题 → 命中 chunk 高亮展示。

### 3.7 客户 360°（04）

- 头部：基础信息 + 阶段 Stepper（可改阶段）+ 关键动作（生成开发信/加入 CRM 语境化按钮）；
- 页签懒加载 + 路由化（[02 §4.2](./02-路由与页面架构.md)）；AI Insights 页签 = InsightCard 群（购买概率/下一步动作）+ 「重新分析」按钮（异步任务模式）；
- Activities 时间线组件 `ActivityTimeline`：按 `ref_type` 图标分流（quote/sales_order 条目随 D6 无数据）。

### 3.8 系统设置（16 P0 部分）

- 登录：邮箱+密码；失败统一提示（防账号枚举）；密码 ≥8 位前端校验；
- 初始化向导：四步 `StepWizard`，断点续走（`onboarding.currentStep`）；邮箱连接步骤含 IMAP/SMTP 表单 + 「测试连接」；
- 邮箱管理：列表（凭据脱敏展示 `****`）+ 连接/断连/重连；
- 审批规则：autoApprove 开关（仅 medium 类型可开；Break-up Email 强制人工审文案为只读说明）+ 员工级 approval_policy 覆盖；
- 员工管理：列表 + 角色变更（仅 admin/manager 可见入口）。

## 4. 交互通用约定

| 项 | 约定 |
|---|---|
| 加载态 | 列表骨架屏 / 详情骨架 / 按钮 loading 三级；禁止整页白屏转圈 |
| 确认 | 不可逆操作（删除/断连/批量）一律二次确认；高风险类型文案差异 |
| 提交防重 | 按钮 loading + Idempotency-Key（[03 §3](./03-状态管理与数据请求.md)） |
| 反馈 | 成功 toast + 必要时路由跳转；失败按错误码管道（[03 §4](./03-状态管理与数据请求.md)） |
| 长列表 | 虚拟滚动阈值：会话消息、任务日志 >200 条；表格 >100 行 |
| 键盘 | 全局 `⌘K` 唤起搜索；Esc 关抽屉；表单 Enter 提交（textarea 除外） |
| 响应式 | 1440 基准；1280 以下 Sider 自动折叠为图标栏；不做移动端（MVP） |
