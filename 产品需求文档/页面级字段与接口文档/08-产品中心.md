## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/products` | 产品列表（keyword/category/status） |
| POST | `/api/v1/products` | 添加产品 |
| GET | `/api/v1/products/{id}` | 详情（含全部页签字段） |
| PUT | `/api/v1/products/{id}` | 编辑产品 |
| POST | `/api/v1/products/{id}/analyze` | AI 分析产品（异步任务） |
| POST | `/api/v1/products/{id}/knowledge/generate` | AI 生成知识（→ status=draft） |
| POST | `/api/v1/products/{id}/knowledge/confirm` | 人工确认启用（→ status=approved） |
| POST | `/api/v1/products/{id}/documents` | 上传产品资料（multipart） |
| DELETE | `/api/v1/products/{id}/documents/{fileId}` | 删除资料 |

---

## 3. 接口详细定义

### 3.1 POST /api/v1/products

请求体：1.7 表单字段。响应：`{ productId }`。
校验：SKU 同企业内唯一（重复返回 `42201`）；保存后触发知识中心归档（分类=产品）。

### 3.2 POST /api/v1/products/{id}/knowledge/generate

请求：`{ sources: ["specifications", "documents"] }` → 响应 `{ taskId }`。

生成完成后的知识条目 `status = draft`，需调用 `confirm` 才对 AI 销售/报价场景可见（需求文档 §4：生成后需人工确认启用）。

### 3.3 POST /api/v1/products/{id}/analyze

响应 `{ taskId }`；产出为分析内容（与 1.6 同结构但仅展示），**不修改产品基础字段**。

---

## 4. 联动与边界

- **AI Knowledge 基于结构化数据与上传资料生成**，`citations` 指向具体文档；禁止编造参数、认证与检测数据。
- Pricing 为结构化字段：报价引擎（09）读取 `costPrice/priceTiers`；AI 无改价接口。
- 产品资料自动归档到 [11-知识中心](./11-知识中心.md)「产品」分类并建立索引。
- 产品参数被 [06-AI销售工作台](./06-AI销售工作台.md) 草稿引用（`citations` 中 docName 即产品知识来源）。
