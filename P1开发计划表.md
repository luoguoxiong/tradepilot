### 1.2 开工前已就绪的基座（省力清单，2026-09-13 核实）

**后端**

- **数据库：P1 相关表全部已建**（Drizzle schema + 迁移 0000~0004 + RLS/FK）——
  - `packages/db/src/schema/06-product-knowledge.ts`：`product / product_spec / product_price_tier / product_document / product_knowledge`（+ `knowledge_document / knowledge_chunk`）
  - `packages/db/src/schema/07-quote-order.ts`：`quotation / quotation_item / sales_order / sales_order_item / order_risk_insight / order_progress_log`（含 `CostSnapshot` 类型）
  - `packages/db/src/schema/08-approval-data.ts`：`business_report / ai_discovery / analytics_daily_summary`（+ `approval_request / approval_log`）
  - `packages/db/src/schema/01-org-user.ts`：`pricing_rule_setting / crm_integration / api_key / webhook`
  - 枚举齐备：`task_status`（含 `paused / canceled`）、`task_type`（含 `product_analysis / order_monitor / business_analysis`）、`quote_status / order_status / order_risk / product_status / discovery_type / report_period`
- **运行时**：`TaskRunner`（乐观锁 claim / resume）、`ApprovalGate`、`LlmGateway`（`llm_call` 记账 + 预算告警）、`GraphCompiler`（`(orgId,taskType@version)` 缓存）、memory、SSE 管道、`PauseAbortError`（员工级协作中断）
- **任务模型**：`POST/GET /tasks`、`/{id}`、`/logs?after=`、`/stream`(SSE)、`/steps`、`/retry`（`retryOf` 溯源）已交付；`q.analysis` 队列映射就绪
- **工具**：`crm_read / crm_write / email_read / email_send / knowledge_search / web_search / site_crawl`
- **审批**：`approvals` 模块 + `quote / order_change` 枚举已就位（**尚无业务侧触发方**）
- **集成**：邮箱三驱动 + 搜索适配 + RAG 入库/混合检索 + 通知分发（`q.notify`）已交付
- **员工级** pause/resume、`follow_up_task` pause/skip 已实现

**前端**

- `web/src/features.ts` 六个编译期开关（`products / quotes / orders / manager / taskCenter / dataCenter`）已就位，默认 p0 全关；`router/routes/modules.ts` 中 P1 路由**已注册为占位**（`PlaceholderView.vue`），settings 下 `crm-integration / pricing-rules / api-keys` 为占位页
- 可复用组件：`ProTable`、`MoneyText`、`InsightCard`、`ApprovalCard`、`DraftEditor`、`StepWizard`、`Uploader`、`useTaskStream / StreamLogPanel / TaskProgressCard`、`CitationPopover`、`ProductDetailDrawer`、`EmptyState / ComingSoon`、三套 skeleton
- query/stores/sse/utils 基座齐备；契约测试直连真实后端（`web/tests/contract/_server.ts`）

### 1.3 P1 主要缺口（必建）

- **后端**：定价引擎（五项成本核算 + 利润红线 + 让价梯度）；`product / quotation / order / reports / analytics / api-key / webhook` 七个 API 模块；`order_monitor` + `business_analysis` 两张 LangGraph 图与 SOP；analytics 预聚合 Cron；任务级 `pause / resume / cancel / transfer-to-human`；Webhook 投递表与重试；D1~D12 恢复
- **前端**：六个 P1 feature 目录与视图、六个 api resource/types、数据中心图表库（ECharts 按需）、设置三子页、D1~D12 恢复
