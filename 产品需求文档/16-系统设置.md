### 3.3 设置子页面字段与交互（v0.4 全量补齐，12 项）

> 字段与 [接口文档 16 §1](./页面级字段与接口文档/16-系统设置.md) 对齐；交付时点标注各子页面进入可用的版本节奏（P0 = MVP，P1 = 第二期）。

#### FR-01 登录 / 企业初始化（P0）

- **字段**：登录 `email* / password*`；注册 `companyName* / contactName* / email* / password*`。
- **登录方式决议（§7.3）**：MVP 仅**邮箱 + 密码**；邮箱验证码、企业微信扫码列 P1，登录接口预留 `loginType` 扩展字段。
- **交互**：登录失败统一提示「邮箱或密码错误」（防账号枚举）；密码 ≥ 8 位；注册即创建 org + 管理员（ER 01 §4 注册事务）；登录后 `onboarding.currentStep < 4` 自动进入初始化向导（4 步见 §3.2），向导步骤可跳过、Dashboard 引导补全。

#### FR-02 企业信息（P0，含区域与本地化）

- **字段**：`orgName* / logo / country / industry / timezone* / defaultCurrency* / defaultLanguage*`（org 表，ER 01 §2.1）。
- **区域与本地化决议（§7.2）**：org 级 3 个默认值纳入 MVP——
  - `timezone`（IANA，默认 `Asia/Shanghai`）：**07 发送时间窗、14 定时任务、13 报告周期、「今天待执行」的统一基准**；
  - `defaultCurrency`（ISO 4217，默认 `USD`）：09 新建报价默认币种（单报价可改，09 汇率快照口径不变）；
  - `defaultLanguage`（默认 `zh-CN`）：界面语言，MVP 支持 `zh-CN / en`，全量多语言文案列 P1。
- **交互**：仅管理员可编辑；`timezone` 变更仅对**新排期任务/策略**生效，进行中任务不回溯；logo 上传 PNG/JPG ≤ 2MB。

#### FR-03 团队成员（P0）

- **字段**：`memberId / name / email / role(admin|manager|sales) / status(active|disabled|invited) / invitedAt / joinedAt`。
- **交互**：邮箱邀请（生成邀请链接，角色必选，初始 `invited` 态）；成员接受后转 `active`；停用即时失效会话与 API 凭证；角色变更即时生效（后续请求按新角色裁剪数据范围）；列表支持按角色/状态筛选；仅管理员可管理。

#### FR-04 AI 员工配置（P0）

- **字段与交互**：**复用 [02-AI数字员工中心](./02-AI数字员工中心.md)**（Role / Goal / SOP / Skills / Tools / Knowledge / Memory / Workflow / Permissions / Approval / KPI 十一项配置），设置侧仅提供入口跳转，不重复实现；SOP 结构化内容不可编辑等边界以 02 §7 澄清决议为准。

#### FR-05 邮箱连接（P0）

- **字段**：`provider(gmail|outlook|smtp_imap)* / account* / imap* / smtp*（host/port/ssl/credential）/ syncScope{historyDays, folders}*`；`status(connected|error|disconnected)` 只读。
- **交互**：保存前「连接测试」（IMAP / SMTP 分别校验并回显结果）；凭据加密存储（ER 01 `credential_enc`）、界面脱敏、接口**永不回显明文**；支持多邮箱连接（06 会话列表按 `mailboxId` 标识来源，06 FR-11）；断连状态红色提示 + 重连入口。

#### FR-06 CRM 集成（P1，MVP 占位）

- **字段**：`provider(小满|富通天下) / status / syncDirection(pull|push|both) / lastSyncAt / mapping`（ER 01 §2.5）。
- **交互**：MVP 仅菜单 + 「即将上线」占位（对齐邮箱模板占位先例）；P1 交付授权连接 → 字段映射 → 同步（`syncDirection` 决定 05 数据进出方向）。

#### FR-07 产品与报价规则（随 09·P1 配套交付）

- **字段**：`productCategories[]* / costItems[]* / profitFloorPct* / discountLadder[]* / defaultIncoterms* / defaultCurrency* / exchangeRateSource*`（ER 01 §2.6 单例）。
- **交互**：`profitFloorPct` 保存后即时生效（09 报价提交 100% 拦截）；五项成本规则供 09 定价引擎读取（09 §7.1 澄清：purchase/freight/insurance/tax/fx）；`exchangeRateSource` MVP 固定 `manual`（汇率人工维护，第三方 API 列 P1+）。

#### FR-08 权限管理（P0）

- **字段**：三角色权限矩阵 `permissions{customers, quotes, approvals, settings}` + `approvalRules[{approvalType, approverRoles}]`（ER 01 §2.3）。
- **交互**：矩阵行内编辑、整页保存；6 类高风险动作（quote / email_send / contract / order_change / bulk_marketing / customer_delete）审批绑定**强制不可配置绕过**（传 `none` → `42201`）；`autoApprove` 开关仅 medium 类型可开（12 §7.1）；数据可见范围 `self / team / all` 与 15 §7.3 口径一致。

#### FR-09 通知设置（P0）

- **字段**：`channels{site, email}` + `events{approval_pending, risk_alert, task_failed}`（ER 01 §2.7 单例）。
- **交互**：开关保存即时生效；站内 = 01 徽标轮询（`GET /approvals/summary` 等）；邮件 = 复用 FR-05 通道发送；12 审批超时提醒收件人为经理（12 §7.2）。

#### FR-10 AI 模型（P0）

- **字段**：`scenes[]{scene*, model*, temperature, maxTokens, budgetLimit}`（ER 01 §2.8，按场景多行，注册时种子初始化）。
- **配置粒度决议（Agent Runtime §10.3）**：**org 级**——org 默认模型路由 + 按场景（对应员工档位 high / medium / low）覆盖；**不提供节点级配置**。
- **预算语义**：MVP 仅记录 token 用量与估算成本（LLM Gateway 记账，Runtime §4.8）；`budgetLimit` 超限**仅告警不熔断**，硬熔断列后续增强。
- **交互**：按场景行编辑；模型变更对新任务生效，运行中任务不中断。

#### FR-11 API / Webhook（P1，MVP 占位）

- **字段**：`apiKey（明文仅创建时返回一次）/ keyPrefix / scopes[] / status`；`webhooks[{url, events[], secret}]`（ER 01 §2.9/§2.10）。
- **交互**：MVP 提供配置界面与凭证管理（接口已定义，见接口文档 16 §2）；事件推送联调 P1；Webhook `secret` 密文存储（`secret_enc`）。

#### FR-12 外发规则（P0，07 依赖）

- **字段**：`sendRules{sendWindow{start, end}*, minTouchIntervalDays*}`（org.send_rules，ER 01 §2.1）。
- **交互**：默认 09:00–18:00（按企业 `timezone` 当地时刻）、`minTouchIntervalDays=3`；修改后仅对**新排期**生效；07 Scheduler 每次入队前实时读取并执行频控预检（07 §7）。

## 4. AI 行为边界

- AI 员工的 **Permissions / Approval 配置决定其自动化上限**：高风险动作（报价、发信、订单变更、删除）必须在配置中强制绑定审批，不可被配置绕过。
- AI 模型配置需支持成本与效果分级：简单场景用小模型，复杂场景用大模型。
- 邮箱连接的凭据属于敏感信息，需加密存储并在界面上脱敏展示。
