## 1. 页面区块与字段清单

### 1.1 知识文档列表（FR-01～04）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| docId | string | ✓ | 文档 ID |
| fileName | string | ✓ | 文件名（如 Carbon Fiber Catalog.pdf） |
| category | string | ✓ | `product` 产品 / `company` 公司 / `sales` 销售 / `customer` 客户 / `faq` / `process` 流程 / `other` |
| status | string | ✓ | indexStatus：`indexed` 已索引 ✓ / `indexing` 索引中 ⏳ / `failed` 失败（含 retry 次数） |
| error | string | — | 失败原因 |
| size / fileType | string | — | 大小 / 格式（pdf/docx/md/txt） |
| uploadedAt / updatedBy | string | — | 上传时间 / 人 |

Tab：`all / product / company / sales / customer / faq`。

### 1.2 知识统计（FR-05）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|

| chunksCount | number | ✓ | Chunks: 2,468 |
| lastIndexedAt | string | ✓ | Last Updated |

### 1.3 检索结果（RAG，FR-06，对内 API）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| docId / docName / chunkId | string | ✓ | 引用溯源三元组 |

## 3. 接口详细定义

### 3.1 POST /api/v1/knowledge/documents

请求：`multipart/form-data`：`file` + `category`。
响应：`{ docId, status: "indexing" }` —— 索引异步执行，前端轮询列表或订阅状态。
校验：格式白名单（pdf/docx/md/txt）与大小上限（待澄清，暂定 50MB），超限 `42201`。

### 3.2 POST /api/v1/knowledge/documents/{id}/retry

响应：`{ status: "indexing" }`；连续失败需明确提示（不允许静默丢失知识）。

### 3.3 POST /api/v1/knowledge/search

请求：

```json
{ "query": "Carbon Fiber Insole 的 MOQ 和优势", "category": ["product"], "topK": 5,
  "scene": "sales_reply" }
```

`scene` 枚举：`lead_match`（获客匹配）/ `sales_reply`（销售回复）/ `follow_up`（跟进内容）/ `pricing_basis`（报价依据）/ `business_analysis`（经营分析）。

响应 `data`：

```json
{ "results": [
  { "docId": "doc_3", "docName": "Carbon Fiber Catalog.pdf", "chunkId": "chk_12",
    "content": "MOQ 500 pairs, lead time 25 days…", "score": 0.91, "category": "product" } ],
  "noResult": false }
```

`noResult = true` 时调用方必须向用户明确提示「知识库中没有相关信息」，禁止编造。

### 3.4 DELETE /api/v1/knowledge/documents/{id}

响应：`{ deleted: true }`；服务端同步失效引用该文档的缓存与产品知识条目（缓存策略待澄清）。

## 4. 联动与边界

- **知识库是 AI 事实的唯一来源**：所有 AI 产出（06 草稿、03 匹配、09 报价依据、13 经营分析）引用必须可回溯 `docId/chunkId`。
- 产品资料（08 Documents）自动归档为 `category=product` 文档。
- 权限：知识按角色可见范围（待澄清），检索接口按调用方权限过滤。
